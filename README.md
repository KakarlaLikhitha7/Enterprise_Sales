# Enterprise Sales Analytics Dashboard

This project demonstrates an end-to-end **Snowflake Medallion Architecture**
with a **Streamlit dashboard** built on top of the **Gold Layer**.

## Tech Stack
- Snowflake (Bronze / Silver / Gold)
- Snowpark Python
- Streamlit
- Pandas

## Features
- Monthly / Quarterly / Half-Yearly / Yearly Sales
- Growth % and Cumulative Revenue
- Dynamic Filters
- CSV Export
- Enterprise-ready Gold Layer usage

## Deployment
- Hosted on Streamlit Community Cloud
- Secure Snowflake connection via secrets
